# Simple Interest Calculator

A simple command-line tool to calculate **Simple Interest** based on user input.

## Overview

This project provides a Bash script that computes simple interest given the principal amount, annual rate of interest, and the time period in years.

## Formula

```
Simple Interest = (Principal × Rate × Time) / 100
```

## Usage

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

The script will prompt you to enter:
- **Principal amount**
- **Annual rate of interest**
- **Time period (in years)**

It will then display the calculated simple interest.

## Example

```
Enter the principal amount: 10000
Enter the annual rate of interest: 5
Enter the time period (in years): 3
The simple interest is: 1500.00
```
